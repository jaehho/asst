Symbolic icons from GNOME's Icon Development Kit (the set Icon Library ships), CC0-1.0.

`scalable/actions/lucide-*-symbolic.svg` are from [Lucide](https://lucide.dev) (ISC license),
made by `scripts/lucide-icons.py`, which turns their strokes into filled outlines so GTK can
recolor them. They label lists (the icon picker in the list dialog); the script pins
the release, and `LUCIDE-LICENSE` is its license.
